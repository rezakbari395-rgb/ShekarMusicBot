# ربات موزیک تلگرام 🎵

اسم آهنگ یا لینک می‌گیره، دانلود می‌کنه و به‌صورت فایل صوتی (با کاور، نام آهنگ و خواننده) تو گروه آپلود می‌کنه.

## امکانات
- `/play اسم آهنگ یا لینک` — جستجو و نمایش ۵ نتیجه با دکمه
- `/top` — پرطرفدارترین آهنگ‌ها
- تو چت خصوصی فقط اسم آهنگ رو بفرست
- **کش هوشمند**: آهنگی که یک‌بار آپلود شده، دفعه‌های بعد فوری ارسال می‌شه (بدون دانلود مجدد)
- محدودیت زمان آهنگ، محدودیت همزمانی دانلود و فاصله‌ی زمانی بین درخواست‌ها (ضد اسپم)
- دکمه‌های نتایج فقط برای کسی که درخواست داده کار می‌کنن

## نصب
1. پایتون ۳.۱۰+ و **ffmpeg** نصب باشه:
   - اوبونتو: `sudo apt install ffmpeg`
   - ویندوز: `winget install ffmpeg`
2. وابستگی‌ها:
   ```
   pip install -r requirements.txt
   ```
3. تو تلگرام به `@BotFather` پیام بده، `/newbot` بزن و توکن بگیر.
4. همون‌جا `/setprivacy` → ربات رو انتخاب کن → **Disable** (که تو گروه‌ها دستورها رو ببینه). اگه ربات ادمین گروه باشه نیازی به این نیست.
5. فایل `.env.example` رو کپی کن به `.env` و توکن رو بذار.
6. اجرا:
   ```
   python bot.py
   ```
7. ربات رو به گروه اضافه کن و `/play` بزن.

## اجرای دائمی روی سرور
```
nohup python bot.py &
```
یا بهتر: یه سرویس systemd یا Docker. برای اینکه yt-dlp کار کنه، هر چند وقت یه‌بار آپدیتش کن:
```
pip install -U yt-dlp
```

## نکات
- محدودیت آپلود Bot API حدود ۵۰ مگابایته؛ برای آهنگ‌های طولانی‌تر باید Local Bot API Server بذاری.
- فقط محتوایی رو دانلود کن که حق استفاده ازش رو داری؛ مسئولیت رعایت قوانین کپی‌رایت و قوانین یوتیوب با خودته.

## ایده‌های بعدی برای «بهترین ربات موزیک» شدن
- پخش زنده تو ویس‌چت گروه (با pytgcalls + یک اکانت کمکی)
- منبع‌های بیشتر (ساندکلود، اسپاتیفای برای متادیتا)
- پلی‌لیست، لایک/دیسلایک و لیدربورد هر گروه
- جستجوی اینلاین (`@botname اسم آهنگ`)
- پنل ادمین و آمار
